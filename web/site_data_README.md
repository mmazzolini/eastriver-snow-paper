# Data of the East River snow-profile site (private)

Data files read by https://mmazzolini.github.io/eastriver-snow-viewer/ (published with the page by the
site repository's workflow). Written by `web/build_web_data.py` of the paper repository; file formats
are described in its docstring.

**Do not make this repository public**: it contains ASO snow depth (`aso23.bin.gz`, `aso24.bin.gz`,
the `aso` field of the `*_ic2.json` files), © Airborne Snow Observatories, Inc., which may be shown for
visualisation but not redistributed. The other files, except the gridded products (`rean_*`), are also
in the Zenodo data record (`website_data/`).
